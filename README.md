# Manual QA Testing Documentation

## Project Overview
This repository contains manual testing artifacts created to demonstrate real-world QA skills,
including test case design, bug reporting, and test planning for web and mobile applications.

## Scope of Testing
- Functional Testing
- UI & UX Testing
- Regression & Smoke Testing
- Cross-browser & Cross-device Testing

## Artifacts Included
- Test Cases
- Bug Reports
- Test Plan
- Test Scenarios

## Tools Used
- JIRA
- Excel / Google Sheets
- Browser DevTools

## Domain
Healthcare, E-commerce, Web Applications
